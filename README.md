
# Calculator Project

Простой калькулятор, написанный на языке Python.

## Возможности

Программа позволяет выполнять следующие операции:
- Сложение двух чисел.
- Вычитание двух чисел.

## Используемые технологии

- Python 3

## Запуск программы

Для запуска необходимо выполнить файл calculator.py.
